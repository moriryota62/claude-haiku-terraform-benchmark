# タスク2: 中程度 (VPC + EC2)

以下の要件を満たすTerraformコード(AWSプロバイダ)を出力してください。
説明文は不要です。コードのみを出力してください。

## 要件

- 新規にVPCを1つ作成する(CIDRはvariableで指定可能、デフォルト 10.0.0.0/16)
- パブリックサブネットを2つ、異なるAZに作成する
- インターネットゲートウェイを作成し、パブリックサブネットからのルートを設定する
- EC2インスタンス用のセキュリティグループを作成する
  - インバウンド: 22番(SSH)と80番(HTTP)のみ許可。SSHは許可するCIDRをvariableで指定可能にする(デフォルトは安全側で0.0.0.0/0にしない設計が望ましい)
  - アウトバウンド: 全許可
- EC2インスタンスを1台、パブリックサブネットに作成する
  - インスタンスタイプはvariableで指定可能(デフォルト t3.micro)
  - AMIは最新のAmazon Linux 2023をdata sourceで取得して使用する
  - 上記セキュリティグループを割り当てる
- タグとして全リソースに Project = "haiku-benchmark" を付与する
- VPC ID、サブネットID一覧、EC2のパブリックIPをoutputで出力する
- AWSプロバイダのregionはvariableで指定可能にする(デフォルト: ap-northeast-1)

## 出力形式

- providers.tf, variables.tf, main.tf, outputs.tf のように複数ファイルに分けても、main.tfに全てまとめても構わない
- 複数ファイルに分ける場合は、各コードブロックの前に `# ファイル名: xxx.tf` を明記すること
